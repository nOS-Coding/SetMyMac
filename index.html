SetMyMac

First-login macOS setup, fully automated. Pick a profile, select your apps, and let SetMyMac handle the rest.

Download Latest Release

How It Works

  1. Choose a profile — Writer, Developer, Gamer, Composer, or one of five others.
  2. Step through the selection screens. Pick browsers, IDEs, emulators, DAWs, and more.
  3. Review your selections and hit Install.
  4. The app downloads and installs everything, reporting progress in real time.
  5. Close the app and start using your machine.

The app resets every launch — nothing is persisted between sessions.

Broken Apps & Fixes

SetMyMac uses a binary-patching approach: the app binary stores app metadata (display name, download URL, Homebrew cask name) in a struct table. "Broken" apps point to a failing URL or outdated cask name, which triggers a setmymac-fallback.sh script that handles the actual installation.

AppIssueFix StrategyStatus
PlayCoverOld cask playcover no longer existsRedirected to playcover-communityFixed
Ryujinx / RyubingProject rebranded; all URLs staleDisplay name, key, URL, and struct entry patched to "Ryubing"; fallback downloads from GitLabFixed
FL StudioNo Homebrew caskFallback downloads DMG directly via redirectFixed
DuckStationOutdated ZIP URLFallback downloads from GitHub latest releaseFixed
iA WriterOnly Mac App StoreFallback installs via mas installFixed
ArdourNo Homebrew cask, paid app officiallyFallback scrapes nightly.ardour.org for free demo DMGFixed
RPCS3Stale download URLFallback fetches latest ARM64/x64 7z from GitHub releases via APIFixed

Note: Binary patches require re-signing with codesign -fs -. The fallback script is at /usr/local/bin/setmymac-fallback.sh.
